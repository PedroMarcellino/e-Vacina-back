# 💉 Sistema de Monitoramento e Cadastro de Vacinas

Este projeto foi desenvolvido como **Trabalho de Conclusão de Curso (TCC)** do curso técnico em **Análise e Desenvolvimento de Sistemas (ADS)**.  
O objetivo principal é fornecer uma solução digital para o **monitoramento e gerenciamento de vacinas**, permitindo o **cadastro, acompanhamento e atualização de informações de imunização** de forma eficiente.

---

## 📌 Objetivos do Projeto
- Facilitar o **cadastro de vacinas** e seus dados principais.  
- Permitir o **acompanhamento e controle** de aplicação.  
- Oferecer um sistema intuitivo, seguro e escalável.  
- Aplicar boas práticas de desenvolvimento com **Laravel**.  

---

## 🛠️ Tecnologias Utilizadas
- **[Laravel](https://laravel.com/)** – Framework PHP para desenvolvimento web.  
- **MySQL** – Banco de dados relacional.  
- **Blade** – Motor de templates do Laravel.  
- **Bootstrap / CSS3** – Estilização e responsividade.  
- **JavaScript** – Interatividade no front-end.  

---

## ⚙️ Funcionalidades
- Cadastro de vacinas com informações detalhadas.  
- Registro de aplicação de vacinas.  
- Histórico de aplicações.  
- Painel administrativo para gestão.  
- Relatórios básicos para acompanhamento.
